    \section{Introduction}
    Regarding this four-class image classification problem, we employs a patch-based approach where images are subdivided into smaller regions. These patches are processed using \textbf{Multiple Instance Learning (MIL)} aggregation techniques to produce a slide-level prediction.
    \section{Problem Analysis}
    The dataset comprises 691 pathology images coupled with pixel-level annotation masks. The samples are categorized into four molecular subtypes: \textbf{Luminal A (30\%)}, \textbf{Luminal B (32\%)}, \textbf{HER2(+) (27\%)}, and \textbf{Triple Negative (11\%)}. As indicated by these statistics, the dataset exhibits significant \textbf{class imbalance}, with \textbf{Luminal B} being the most prevalent and \textbf{Triple Negative} being underrepresented.

    For feature extraction, we extract patches from annotated regions to form MIL bags (see Figures~\ref{fig:patches_example1} and~\ref{fig:patches_example2}). However, limited mask coverage in some images results in sparse bags, which risks overfitting.

    To address this, we expanded our sampling criteria:
    \begin{enumerate}
        \item \textbf{Boundary Inclusion:} We extract patches from the mask periphery to increase bag size and capture contextual information.
        \item \textbf{Normal Tissue Padding:} If the patch count remains insufficient, we supplement the bag with normal tissue patches. This ensures consistent bag sizes and helps the model distinguish tumor features from the background.
    \end{enumerate}

    \section{Method}
    \subsection{Noisy image recognition}
    We observed that some images in the dataset are noisy or corrupted (Orcs and Slime), which can negatively impact model performance. To address this, we used two layers of defense:
    \begin{itemize}
        \item \textbf{Color Check}: Histology images are never green. If an image has significant green pixels (common for orcs/slimes), it is immediately trashed.
        \item \textbf{CLIP Classification}: Use \textbf{openai/clip-vit-large-patch14} to identify and filter out these noisy images from the training set. We create text prompts like "a histology image" and "a green slime histology image" to classify images. If an image is classified as "green slime histology image" with high confidence, it is marked as noisy.
    \end{itemize}
    Finally, we removed \textbf{101} noisy images from the training set, get \textbf{590} clean images for training.

    \subsection{Data Augmentation}
    We utilized the \textbf{ImageNet AutoAugment policy} to align with our backbone's pre-training on the ImageNet dataset. This facilitates effective transfer learning by ensuring input variations remain compatible with the pre-trained weights, while introducing diverse regularization (e.g., geometric and color shifts) to prevent overfitting on the limited pathology data.

    \subsection{Dual-stream MIL Network}
    We employ a Dual-Stream Multiple Instance Learning (MIL) architecture~\cite{li_dual-stream_2021} to synergize local morphological details with global spatial context. As illustrated in Figure~\ref{fig:dual_stream_mil}, the framework operates via two parallel pathways: a \textit{Local Stream} (Bag of Instances) and a \textit{Global Stream} (Contextual View), which are fused for final classification.

    \begin{figure}[H]
        \centering
        \includegraphics[height=0.5\textheight]{Dual-Stream-MIL.png}
        \caption{Dual-Stream MIL Architecture}
        \label{fig:dual_stream_mil}
    \end{figure}

    \paragraph{Local Stream}
    This stream processes the bag of extracted patches. A shared backbone extracts feature embeddings from each instance, which are subsequently projected into a lower-dimensional space via a bottleneck layer.

    \paragraph{Optional Mask Fusion}
    To leverage the available segmentation annotations, we integrate an optional mask fusion step. Binary mask information is concatenated with patch embeddings to explicitly guide the network toward relevant pathological regions.

    \paragraph{MIL Aggregation}
    We apply a permutation-invariant aggregation function to the instance embeddings. This synthesizes the varying number of patch features into a fixed-length, slide-level representation.

    \paragraph{Global Stream}
    To capture macro-architectural patterns often lost during tiling, the global stream processes a downsampled view of the entire image using a backbone. Similar to the local stream, these global features are compressed via a bottleneck projection before fusion.

    \section{Experiments}
    We conducted extensive experiments to evaluate the Dual-Stream MIL model, assessing the impact of patch selection, aggregation strategies, and backbones.

    \paragraph{Patch Extraction}
    Patches of $224 \times 224$ pixels were extracted with a stride of 112. Using the binary masks, we discarded patches containing less than 50\% tissue. To handle class imbalance during training, we utilized a \textbf{WeightedRandomSampler}. Empirically, we determined that a bag size of approximately 8 patches offered the optimal trade-off between computational efficiency and representational power.

    \paragraph{Aggregation Method}
    We benchmarked various MIL aggregation techniques, including Max Pooling, Mean Pooling, Attention-based Pooling, Gated Attention, TransMIL, and \textbf{CLAM} (Clustering-constrained Attention Multiple instance learning). We found that \textbf{CLAM} yielded the best performance, effectively learning instance-level importance to refine slide-level predictions.

    \paragraph{Optimizer}
    Training was performed using the \textbf{AdamW} optimizer with a learning rate of $1 \times 10^{-4}$ and weight decay of $1 \times 10^{-2}$. We also explored the \textbf{Lion} optimizer but observed more stable convergence with AdamW.

    \section{Discussion}
    Our experiments demonstrate that the architectural choice for the Local and Global streams significantly impacts performance. As shown in Table~\ref{tb:Measurements}, the combination of \textbf{ConvNeXt-Tiny} (Local) and \textbf{ResNet-18} (Global) yielded the highest F1-score of \textbf{0.4226}, outperforming other configurations. For the model selection throughout the entire experimental process, please refer to the ~\ref{sec:appendix}.

    We attribute this success to two main factors. First, ConvNeXt designs modernize the standard ResNet architecture with depth-wise convolutions and larger kernels, allowing it to capture more robust morphological features from local patches without a massive increase in parameters. Second, the use of a lightweight \textbf{ResNet-18} for the global stream proved sufficient for capturing macro-spatial context without overfitting.

    Notably, larger backbones such as \textbf{ResNet-50} performed poorly (0.3116 F1-score). Given the limited size of our clean training set (590 images), deeper models likely suffered from severe overfitting, failing to generalize to the validation set. This confirms that for small-scale histology datasets, model compactness and inductive bias (as seen in ConvNeXt) are more critical than raw model depth.

    \section{Future Improvements}
    We propose the following strategies:

    \begin{itemize}
        \item \textbf{Contrastive Representation Learning:} Rather than relying solely on ImageNet weights, we propose using self-supervised contrastive frameworks (e.g., SimCLR or MoCo) on the pathology patches. This would allow the backbone to learn invariant tissue representations by pulling similar features together and pushing dissimilar ones apart before classification begins.

        \item \textbf{Generative Data Synthesis:} To overcome the limited dataset size, we could employ conditional Generative Adversarial Networks (cGANs) or Diffusion models conditioned on the segmentation masks. This would allow us to "synthesize" new, realistic training images with diverse textures while preserving the original morphological structures.
    \end{itemize}
